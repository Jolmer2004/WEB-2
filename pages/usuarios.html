Gestion de usuarios

CRUD completo conectado al usuario-service (puerto 8082).

🔑 Token JWT (Keycloak)

Obtén un token con curl y pégalo aquí para autenticar las peticiones. Con alice (USER) solo puedes consultar. Con admin_user (ADMIN) puedes crear, editar y eliminar.

Sin token — las peticiones devolverán 401.
Ver comandos curl para obtener tokens ▾ 
# Token para alice (rol USER — solo lectura)
curl -s -X POST \
  "http://localhost:8090/realms/curso-springboot/protocol/openid-connect/token" \
  -d "grant_type=password&client_id=usuario-service&username=alice&password=alice123" \
  | python3 -c "import json,sys; print(json.load(sys.stdin)['access_token'])"

# Token para admin_user (rol ADMIN — lectura y escritura)
curl -s -X POST \
  "http://localhost:8090/realms/curso-springboot/protocol/openid-connect/token" \
  -d "grant_type=password&client_id=usuario-service&username=admin_user&password=admin123" \
  | python3 -c "import json,sys; print(json.load(sys.stdin)['access_token'])"
